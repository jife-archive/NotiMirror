# NotiMirror

macOS 알림(Slack, 카카오톡, 메일 등 모든 앱)을 연결된 **모든 모니터**에 같이 띄워 주는 메뉴바 앱.

## 동작 방식

- macOS는 알림 배너를 주 디스플레이에만 띄운다.
- NotiMirror는 알림 센터가 쓰는 DB(`~/Library/Group Containers/group.com.apple.usernoted/db2/db`)를 0.75초마다 읽기 전용으로 확인한다.
- 새 알림이 들어오면 나머지 모니터 우측 상단에 같은 모양의 배너를 띄운다.
- 배너 동작
  - 클릭하면 해당 앱이 열리고, 모든 화면의 같은 알림이 함께 닫힌다.
  - 마우스를 올리면 닫기 버튼이 나오고, 올려 둔 동안은 사라지지 않는다.
  - 한 화면에 최대 4개까지 쌓인다.

## 설치

```bash
./build.sh --install
```

이렇게 하면 `~/Applications/NotiMirror.app`에 설치되고 바로 실행된다. 처음 실행하면 **전체 디스크 접근 권한**을 요청한다.
- 위치: 시스템 설정 › 개인정보 보호 및 보안 › 전체 디스크 접근 권한
- 목록에 NotiMirror가 없으면 `+`로 추가하거나 Finder에서 끌어다 놓는다.
- 개발 인증서로 서명하므로 다시 빌드해도 권한이 유지된다.

## 메뉴바 메뉴

| 항목 | 설명 |
|---|---|
| 일시 정지 | 복제를 잠시 끈다 |
| 주 디스플레이에도 표시 | 원본이 뜨는 화면에도 복제본을 띄운다 (기본: 끔) |
| 표시 시간 | 4 / 6 / 10 / 20초 |
| 로그인 시 자동 실행 | 로그인 항목으로 등록한다 |
| 배너 미리보기 | DB와 상관없이 배너 모양만 확인한다 |
| 테스트 알림 보내기 | 실제 시스템 알림을 보내 전체 흐름을 확인한다 |
| 로그 보기 | `~/Library/Logs/NotiMirror.log` (알림 내용은 기록하지 않음) |

## 알려진 한계

- 알림 센터 DB 구조는 Apple이 공개한 것이 아니어서, macOS 업데이트 후 동작이 깨질 수 있다. 그럴 땐 로그를 확인한다.
- 집중 모드나 앱별 "배너 없음" 설정으로 원본 배너가 숨겨진 알림도 복제될 수 있다.
- 답장이나 액션 버튼은 복제되지 않는다. 클릭하면 해당 앱이 열리는 것까지만 지원한다.
